# START HERE NEXT

Continue this repository as the low-level audio substrate.

## First build

Implement the smallest honest offline core that can:
1. represent an `axm.audio-atom/v1`;
2. generate one procedural SFX tone/noise recipe;
3. apply an envelope and at least one filter/effect;
4. represent a positional/runtime cue;
5. render or export evidence;
6. reproduce the same result from the same canonical recipe.

Prefer a tiny dependency-light implementation over a GUI first.

## Then

Add:
- sample import;
- pitch/time transforms;
- buses and sends;
- spatialization;
- layered SFX recipes;
- game cue adapter for Gameplay Ability Fabric;
- explicit integration contract for Sound Mixer.

Do not absorb Music Maker or Sound Mixer responsibilities merely because audio code is nearby.

## Truth boundary

Generated bytes prove execution, not good sound. Keep objective signal checks separate from listening/creative acceptance.
